**Ожидание:** INVALID_QR (422) или QR_EXPIRED (410), платёж не создан.
**Факт A:** подпись изменена только в временной копии qr_002; получен INVALID_QR (422), 0 строк платежей.
**Факт B:** исходная подпись, время позже exp; получен QR_EXPIRED (410), 0 строк платежей.
**Пройден:** [x] да [ ] нет.

Подпись проверяется до срока действия. Два разных входа разделены, чтобы было понятно, какой код ожидается. Входные CSV проекта не редактировались. Отказы записаны в аудит без создания Payment.

**Факт B:** qr_001 после подтверждения остаётся PENDING; отмена вернула CANCEL_NOT_ALLOWED, HTTP 409, статус сохранился.
**Пройден:** [x] да [ ] нет.

Дополнительно проверены запрет отмены SUCCESS, токен подтверждения, отсутствие второго вызова шлюза при повторном confirm и события аудита.
