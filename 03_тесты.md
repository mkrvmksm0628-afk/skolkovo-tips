# Проверки доработанного исходного шаблона

Автоматические проверки выполнялись при доработке; вспомогательный скрипт удалён из проекта по решению команды. Сохранённый протокол относится к этому прошлому запуску: все 6 групп проверок прошли. Выходы тестов создаются во временной папке; часы подменяются в тестах. В обычном CLI всегда настоящее UTC-время.

Проверены исходы SUCCESS/DECLINED/TIMEOUT, суммы 31.85 и 668.85; истёкший QR; неверная подпись; неправильный ввод и диапазоны; граница срока и неверная дата; округление 0.015 → 0.02 и верхняя граница суммы. Протокол — evidence/tests.log.

| Сценарий задания | Текущее состояние |
|---|---|
| T3-1: qr_001 → SUCCESS | Формула даёт TIMEOUT / GATEWAY_TIMEOUT; суммы верны |
| T3-2: qr_003 → DECLINED | Формула даёт SUCCESS; противоречие задания |
| T3-3: неверный/истёкший QR | Проверено: INVALID_QR / QR_EXPIRED, платежа нет |
| T3-4: повтор ключа | Не реализован исходным шаблоном |
| T3-5: отмена | Не реализована исходным шаблоном |

Функции и формат данных организаторов сохранены. Это проверка демонстрационного шаблона, не полное выполнение всех требований системы.
