# Онлайн чаевые — учебный кейс 3

04_прототип.py доработан непосредственно из исходного шаблона организаторов. Сохранены все семь функций с прежними параметрами, константы, порядок main(), поля CSV/JSON, значения по умолчанию суммы 1500 и чаевых 10%, учебный payment_id и timestamp. SQLite не используется.

## Запуск

```powershell
python .\04_прототип.py .\examples\qr_001.json
```

CSV находятся в корне проекта. Результат добавляется в payments_out.csv. Исходные CSV не изменяются.

Входной JSON: qr_id, необязательные base_amount и tip_pct. Остальные поля старых примеров не обрабатываются этим шаблоном. Отдельного режима --demo нет: проверка срока всегда использует текущее UTC-время. QR из 2025 года сейчас возвращают QR_EXPIRED. В тестах часы подменяются только средствами unittest.mock, исходные QR не меняются.

## Что доработано

Заполнены check_exp и ветви DECLINED/TIMEOUT в emulate_gateway. Исправлен путь к QR. Деньги рассчитываются Decimal с HALF_UP; сумма положительная до 1 000 000, с точностью до копейки, процент 0–50; NaN и бесконечность запрещены. Ошибки входного JSON, значений и файлов обрабатываются. Для существующего пустого CSV записывается заголовок.

HMAC, его payload и публичный учебный SECRET оставлены как в шаблоне. Это демонстрационный ключ, не производственный секрет. Формула шлюза не изменена: qr_001 → TIMEOUT, qr_003 → SUCCESS. TIMEOUT сохранён именно как исходный статус шаблона; в целевой модели системы тайм-аут соответствует незавершённому PENDING.

## Ограничения исходной основы

Учебный ID зависит от QR и повторяется при повторных запусках. timestamp — фиксированная дата из шаблона, а не время фактического запуска. Эти поля оставлены без изменений по требованию сохранить основу. Каждый запуск добавляет строку: идемпотентности и защиты от повторной оплаты нет. Нет проверки ресторана, сотрудника и receipt_id, отмены, отдельного подтверждения и аудита. Не реализованы сервер, интерфейс и реальные платежи.

Документы, OpenAPI и диаграммы описывают целевую систему, а не возможности CLI. Указания о более широкой реализации в прежних материалах не относятся к этому шаблону. Старые PDF/PPTX удалены; тексты защиты находятся в Markdown.
