# Онлайн чаевые — учебный кейс 3

Проект платформы и простой консольный прототип на основе кода участника команды. Программа имитирует оплату без реальных списаний. Только стандартная библиотека Python; SQLite не используется.

## Запуск

```powershell
$env:HMAC_SECRET = 'demo-secret-k3'
python .\04_прототип.py .\examples\qr_001.json --demo
python .\10_tests.py
```

Ключ — публичное демонстрационное значение из задания. Программа читает его из окружения; .env автоматически не загружается.

`--demo` устанавливает часы на 2025-11-01T18:00:00Z для исторических QR. Проверка срока остаётся включённой. Без флага используются реальные UTC-часы и старые QR отклоняются. Ответ содержит demo=true для учебного времени.

Запрос: qr_id, receipt_id, base_amount, tip_pct. Примеры — в examples. Поддерживается только action=pay (по умолчанию). idempotency_key из старых примеров не обрабатывается.

## Что делает программа

Читает JSON → проверяет HMAC и срок QR → проверяет активность ресторана, связь сотрудника и номер чека → проверяет сумму и процент → считает чаевые Decimal с HALF_UP → вызывает эмулятор → добавляет строку в payments_demo_out.csv.

Сумма: 0 < base_amount ≤ 1 000 000, не более двух знаков после запятой; чаевые: 0–50%. Итог при этих ограничениях не превышает 1 500 000. Каждый запуск получает уникальный payment_id. Дата соответствует выбранным часам. Ошибки выводятся в JSON. Код завершения 0 — SUCCESS, 1 — иной результат.

CSV лежат в корне. Исходные CSV программа не изменяет. Выходной CSV исключён из Git.

## Ограничения

Это демонстрация, а не полная реализация требований. Нет идемпотентности, защиты от повторной оплаты QR, подтверждения отдельным запросом, отмены, запроса статуса и журнала аудита. Каждый запуск — новая попытка. Нет сервера, авторизации, регистрации, интерфейса и банковской интеграции. Эти процессы описаны как проект системы в остальных документах, YAML и диаграммах.

При тайм-ауте сохраняется PENDING / GATEWAY_TIMEOUT; дальнейшего опроса шлюза нет. Формула задания сохранена: qr_001 даёт тайм-аут, qr_003 — успех. Поэтому исходные ожидания T3-1 и T3-2 противоречат формуле.
