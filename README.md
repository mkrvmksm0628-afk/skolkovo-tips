## Как скачать проект

На странице репозитория нажать **Code → Download ZIP**, распаковать архив и открыть PowerShell в распакованной папке. Ссылка открывается без приглашения в репозиторий.

Если установлен Git, можно скачать командой:

```powershell
git clone https://github.com/mkrvmksm0628-afk/skolkovo-tips.git
cd skolkovo-tips
```

Просмотр и скачивание доступны всем. Изменять файлы на GitHub могут владелец и приглашённые им участники; публичный доступ сам по себе не выдаёт право записи.

## Как запустить проверки

Нужен Python 3 с установленной стандартной библиотекой; для самого прототипа и тестов сторонние пакеты не требуются. Команды выполняются из папки проекта:

```powershell
$env:HMAC_SECRET = 'demo-secret-k3'
python .\10_tests.py
```

`demo-secret-k3` — открытое демонстрационное значение из выданного задания, а не личный ключ участника или производственный секрет. Python-программа читает его из окружения. Доступ к камере, Windows Hello, личным SSH/API-ключам для запуска не требуется.

Ожидаемый итог: **17 проверок, 15 пройдены, 2 expected failures** из-за исходных противоречий. Надпись `OK (expected failures=2)` не означает, что исходные T3-1 и T3-2 прошли. Полные факты — [03_тесты.md](03_тесты.md), [протокол запуска](evidence/tests.log) и [машиночитаемые результаты](evidence/test_results.json).

## Как запустить CLI

```powershell
python .\04_прототип.py .\examples\qr_001.json
python .\04_прототип.py .\examples\qr_003.json
```

При текущей дате оба исходных исторических QR дают `QR_EXPIRED`. Их срок истёк в 2025 году. В автоматических тестах используются часы на дату учебного набора; обычный CLI сохраняет проверку настоящего времени и не имеет настройки принудительного ответа шлюза.

Запрос содержит `qr_id`, `receipt_id`, `base_amount`, `tip_pct`, `idempotency_key`. Действие `pay` создаёт и сразу подтверждает платёж, как исходный прототип. `create` создаёт `CREATED` и возвращает `confirm_token`; `confirm` подтверждает с этим токеном; `cancel` отменяет только `CREATED`; `status` возвращает состояние по `payment_id`.

При таймауте проверяется тот же платёж; новый ключ для повторной оплаты занятого QR не создаётся.

## Что создаёт программа

`payments_state.sqlite3` хранит локальные состояния, ключи повторов и аудит; `payments_out.csv` и `audit_out.jsonl` — выгрузки для просмотра. Эти служебные файлы исключены из Git. SQLite входит в Python, отдельный сервер базы данных не требуется.

Программа имитирует платёж без реальных списаний. Роли, регистрация, генерация QR, четыре экрана и отчётность спроектированы в документах; полноценный сайт, многопользовательская авторизация и банковская интеграция не реализованы. HTTP-коды в JSON поясняют API-контракт, а не работу веб-сервера.
